## In order

1. **Search the help.** Articles and uploaded training documents are searched
   together.
2. **Ask NextGen2.** It answers from the same content and cites what it used.
3. **Raise a ticket** if neither helped.

## What a ticket carries

When you raise one, NextGen2 attaches the technical context automatically: the
screen you were on, the application, the execution if there was one, your
browser, and the last error. You do not need to gather any of it, and whoever
picks the ticket up does not need to ask.

## If the ticket cannot be filed

If the ticketing system is unreachable, your ticket is still saved in NextGen2
with the reason recorded. You will not be asked to write it out again.

## Questions that find nothing

Every question that returns no answer is recorded. That list is how the
missing articles get written, so asking something the help does not cover is
useful even when it does not help you in the moment.
